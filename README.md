# WeekBar Releases

Public distribution repository for [WeekBar](https://github.com/hisass/WeekBar).

This repository contains only public release metadata and downloadable artifacts:

- Sparkle `appcast.xml` via GitHub Pages
- Notarized WeekBar ZIP or DMG files via GitHub Releases
- Public release notes

The WeekBar source repository is private. Source code, signing keys, certificates,
notarization credentials, API tokens, and other secrets must never be committed here.

## Distribution layout

- `docs/appcast.xml`: signed Sparkle update feed (created on the first release)
- GitHub Releases: signed and notarized application archives
- GitHub Pages: HTTPS hosting for files under `docs/`
